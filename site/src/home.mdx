## Two ways to use it

<div class="ways not-content">
  <article class="way">
    <h3><span class="ico"><Icon name="document" size="1.15rem" /></span>In a project</h3>
    <p>Pull CSS libraries, scripts, fonts or configs into your repo. Commit the config and lockfile, and everyone gets the same bytes.</p>
    <ul>
      <li>Single files, whole folders or glob patterns</li>
      <li>Pinned to a release, a tag or a commit</li>
      <li>Config in TOML, YAML, JSON, JSON5 or <code>package.json</code></li>
    </ul>
    <a class="more" href="/vendorfiles-rs/getting-started/quick-start/">Project quick start →</a>
  </article>
  <article class="way">
    <h3><span class="ico"><Icon name="laptop" size="1.15rem" /></span>On your machine</h3>
    <p>Install command-line tools and apps by name, on Windows, macOS and Linux. One config file lists everything you installed.</p>
    <ul>
      <li><code>vendor add rg fd</code>, with no asset names to look up</li>
      <li>Windows installers that run silently and uninstall cleanly</li>
      <li><code>vendor outdated</code> across every program at once</li>
    </ul>
    <a class="more" href="/vendorfiles-rs/getting-started/global-programs/">Global programs guide →</a>
  </article>
</div>

## What it can fetch

<div class="feats not-content">
  <a class="feat" href="/vendorfiles-rs/configuration/folders-and-globs/">
    <span class="ico"><Icon name="document" size="1.15rem" /></span>
    <span><b>Files, folders and globs</b>One file, a whole folder, or every file a pattern matches, from any repository.</span>
  </a>
  <a class="feat" href="/vendorfiles-rs/configuration/versions/">
    <span class="ico"><Icon name="cloud-download" size="1.15rem" /></span>
    <span><b>Release assets and archives</b>Name an asset once with <code>{'{version}'}</code>, and take only the files you need from zip, tar, 7z or crx.</span>
  </a>
  <a class="feat" href="/vendorfiles-rs/configuration/other-sites/">
    <span class="ico"><Icon name="external" size="1.15rem" /></span>
    <span><b>Any URL</b>Download from any site, and read its latest version from a page, a redirect or JSON.</span>
  </a>
  <a class="feat" href="/vendorfiles-rs/getting-started/program-registry/">
    <span class="ico"><Icon name="magnifier" size="1.15rem" /></span>
    <span><b>Programs by name</b>The registry knows each tool's assets on every platform, and <code>vendor search</code> finds them.</span>
  </a>
  <a class="feat" href="/vendorfiles-rs/configuration/installers/">
    <span class="ico"><Icon name="window" size="1.15rem" /></span>
    <span><b>Windows installers</b>Run NSIS, Inno, MSI and MSIX setups silently, and uninstall them later.</span>
  </a>
  <a class="feat" href="/vendorfiles-rs/reference/lockfile/">
    <span class="ico"><Icon name="rocket" size="1.15rem" /></span>
    <span><b>Fast, incremental updates</b>Downloads run in parallel and stream to disk, and updates reuse files that didn't change.</span>
  </a>
</div>
