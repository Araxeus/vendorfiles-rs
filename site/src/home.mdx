## What it does

<div class="features not-content">
  <div class="feature">
    <p class="feature-title"><Icon name="document" size="1.25rem" />Any file, any source</p>
    <p class="feature-text">Download single files from any GitHub repository or any URL.</p>
  </div>
  <div class="feature">
    <p class="feature-title"><Icon name="download" size="1.25rem" />Release assets</p>
    <p class="feature-text">Unpack only the files you need from zip, tar, tar.gz and crx archives.</p>
  </div>
  <div class="feature">
    <p class="feature-title"><Icon name="random" size="1.25rem" />Releases, tags or commits</p>
    <p class="feature-text">Track a dependency by release, git tag, commit or a version URL.</p>
  </div>
  <div class="feature">
    <p class="feature-title"><Icon name="setting" size="1.25rem" />Your config format</p>
    <p class="feature-text">Write the config in TOML, YAML, JSON, JSON5 or <code>package.json</code>.</p>
  </div>
  <div class="feature">
    <p class="feature-title"><Icon name="rocket" size="1.25rem" />Fast</p>
    <p class="feature-text">Downloads run in parallel and stream straight to disk.</p>
  </div>
  <div class="feature">
    <p class="feature-title"><Icon name="laptop" size="1.25rem" />One binary</p>
    <p class="feature-text">A single static binary, with nothing else to set up.</p>
  </div>
</div>

## Next steps

<div class="steps-grid">
<CardGrid>
  <Card title="Write a config" icon="document">
    List the files you want in `vendor.json`, `vendor.yml` or `vendor.toml`. See [config files](/vendorfiles-rs/configuration/config-files/).
  </Card>
  <Card title="Sync your files" icon="rocket">
    `vendor sync` downloads them, and `vendor update` keeps them current. Try the [quick start](/vendorfiles-rs/getting-started/quick-start/).
  </Card>
  <Card title="Install tools by name" icon="magnifier">
    `vendor add rg fd` installs programs from the [program registry](/vendorfiles-rs/getting-started/program-registry/).
  </Card>
</CardGrid>
</div>
