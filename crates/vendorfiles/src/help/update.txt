Usage: vendor update|upgrade|bump|up|u [options] [names...]

Update all/selected dependencies to their latest version (the tag of the latest
release)

Options:
  --pr                 Output pull request text for gh action (default: false)
  --allow-installers   Run installers from a config that is not your own
  -h, --help           display help for command

Examples:
    vendor update
    vendor bump React
    vendor update React Express
